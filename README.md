# Project2c
:

🧮 Simple Calculator (C Language)
This is a terminal-based calculator built in C that supports basic arithmetic operations such as addition, subtraction, multiplication, division, modulus, and exponentiation. It uses a menu-driven approach and demonstrates key C programming concepts like functions, conditionals, loops, and error handling.

📋 Features
📌 Addition, Subtraction, Multiplication

🔁 Division with zero-checking

🧮 Modulus (for integers)

💥 Power calculation using pow()

✅ Input validation

🔄 Loop until user chooses to exit

🛠️ Technologies Used
Language: C

Libraries:

stdio.h (for input/output)

math.h (for pow() and NAN)
